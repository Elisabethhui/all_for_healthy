# 长沙古本与宋本深度异文考据库规范 (Canon Variant Specification)

本考据库为 `all_for_healthy` 系统的核心文献真理库，旨在系统考辨张仲景第十二次亲改定稿——**长沙古本（白云阁藏本 / 刘宪璜旧藏本）**与通行之**宋本（明万历赵开美复刻宋本）**的异文原貌。

---

## 一、 考据收录准则

1. **版本纯粹性**：以白云阁木刻本（黄竹斋刊本）为长沙古本底本，以赵开美万历翻刻宋本为宋本底本；
2. **异文深度解析**：不仅罗列文字字句差异，更重点阐明字句差异背后的**临床辨证、方药剂量与法度转向**；
3. **结构神全原则**：系统呈现古本特有的十六卷伤寒杂病合编体系与《六气主客篇》运气气化原旨。
