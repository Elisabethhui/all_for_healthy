# 物理量化与可视化精准脉诊 (Physics-Based Visual Pulse Diagnosis)

本模块彻底剔除“如循长竿”、“如微风吹鸟背上毛”等文学玄想比喻，建立一套**屏幕前任何人看图、懂力学、有实物触觉标定即可掌握的精准把脉与自学体系**。

---

## 1. 物理四维坐标量化（位 · 数 · 形 · 势）

任何脉象均可通过四根物理轴线进行精确定位：

| 物理轴 | 判定指标 | 量化检测标准 | 屏幕读取数值 | 对应直接病机 | 代表脉象 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **位 (Depth)** | 纵向压力深度 | **浮取**：0~50g 压力，触皮毛即见<br>**中取**：50~150g 压力，触肌肉肌腱<br>**沉取**：>150g 压力，重按至骨筋 | 浅 / 中 / 深 | 浮：病在表、虚阳浮越<br>中：和缓有胃气<br>沉：病在里、阴寒、水饮深伏 | 浮脉 vs 沉脉 |
| **数 (Rate)** | 脉动频率与节律 | **迟**：< 60 次/分<br>**缓**：60~72 次/分<br>**数**：> 85~90 次/分<br>**促/结/代**：早搏、房颤、间歇 | bpm 数值 | 迟：阳衰虚寒<br>缓：平人胃气<br>数：热盛或阴虚内热<br>结代：心阳不整、脏气衰微 | 迟脉 vs 数脉 vs 结代脉 |
| **形 (Geometry)** | 血管粗细与管壁张力 | **粗细**：细脉（管径 < 1.5mm） vs 大脉（管径 > 3.0mm）<br>**张力**：弦脉（抗指高张力） vs 濡软（张力塌陷）<br>**流体**：滑脉（圆滑流利） vs 涩脉（粗糙迟滞） | 截面图与管壁张力 | 细：阴亏血虚、寒厥水饮<br>大：阳盛气实<br>弦：少阳枢机、水饮、肝胆郁结<br>滑：痰湿水饮、宿食宿垢、妊娠<br>涩：精伤血少、气滞血瘀 | 细脉 vs 洪脉 vs 弦脉 vs 滑脉 vs 涩脉 |
| **势 (Force)** | 搏动动量与回弹性 | **虚**：按之软塌、无抗力、散乱无根<br>**实**：按之坚硬、搏动有力抗指 | 力度波幅 | 虚：正气亏耗、脱阳脱阴<br>实：邪气炽盛、燥屎宿食 | 虚脉 vs 实脉 |

## 2. 屏幕前自学者的“日常实物触觉标定法”（Tactile Calibration）

在没有临床病人时，用身边常见物体建立手指的触觉感知基准：

1. **浮脉【浮水软木塞】**
   - **标定感觉**：手指轻按浮在水面上的软木塞。轻放指腹立即感受到弹力与浮动；稍一用力深按，木塞即没入水中，指下落空减弱。
2. **沉脉【隔棉被按纽扣】**
   - **标定感觉**：隔着一层厚棉被或厚呢子大衣，去摸压底下一颗坚硬的小塑料纽扣。轻抚表面毫无感觉，必须用手指使劲下压穿透棉絮、抵达硬板，才能明确感知纽扣的坚硬轮廓。
3. **弦脉【紧绷的吉他 2 号尼龙弦】**
   - **标定感觉**：用食指、中指、无名指横搭在一根调准音、拉得极紧的吉他 2 号或 3 号琴弦上。指下是一条挺直不弯、截面分明、富有反弹张力与硬度的线状物。
4. **滑脉【盘底滚玻璃弹珠】**
   - **标定感觉**：在一个平底瓷盘里涂少许食用油，放一颗光滑的玻璃弹珠。手指轻轻按在弹珠上向前推动，弹珠在指腹下圆滑、灵动、滑利地滚动，绝无一丝阻滞感（“如盘走珠”）。
5. **涩脉【指腹划细砂纸】**
   - **标定感觉**：指腹逆向轻轻滑过一张 400 目的细砂纸，或者用指甲刮过生锈的铁丝。往来极不顺畅，有一种微小的沙砾顿挫感与摩擦阻力（“如轻刀刮竹”）。
6. **芤脉【横按煮熟的空心大葱】**
   - **标定感觉**：拿一根煮熟放凉的大葱管横放，手指按上去。初按时两边管壁饱满充盈，但手指一旦陷进去，中间是空的软塌无物（“浮大中空，如按葱管”）。
7. **微脉/弱脉【浸水湿棉花球】**
   - **标定感觉**：手指轻摸一团浸透温水的脱脂棉球。极软极细，毫无骨架支撑，手指稍微加力，棉球即被压扁，几乎感知不到内部的搏动支撑。

## 3. 脉搏波流体可视化模型（生物物理脉图）

```
        主波 (P波/上升支)
          /\
         /  \    重搏前波 (T波)
        /    \      /\
       /      \    /  \      重搏波 (D波)
      /        \  /    \      /\
     /          \/      \    /  \
    /         降中峡     \  /    \
   /                      \  /    \
  ───────────────────────────────────────
```
- **波形特征解读**：
  - **上升支陡直无延缓**：心阳充足，血管阻力顺应良好；
  - **上升支倾斜平缓**：心气虚衰，推动无力；
  - **重搏前波（T波）高耸抬起**：中焦湿阻、血管张力过高、少阳郁闭；
  - **降中峡深陷**：外周微循环极度开放（如外感初期大热、虚脱）；
  - **重搏波（D波）低平消失**：肾气衰竭、下焦真阳不固。

## 4. 寸口三维全息病灶定位（寸关尺全息雷达）

```
【左手寸关尺 (心·肝胆·肾阴)】              【右手寸关尺 (肺·脾胃·肾阳)】
┌─────────────────────────┐              ┌─────────────────────────┐
│ 寸：头面、脑、颈项、心   │              │ 寸：咽喉、气管、双肺、胸 │
├─────────────────────────┤              ├─────────────────────────┤
│ 关：左胸胁、肝脏、胆囊   │              │ 关：胃脘、胰腺、脾土、膈 │
├─────────────────────────┤              ├─────────────────────────┤
│ 尺：下腹盆腔、肾阴、前列腺/子宫 │        │ 尺：腰骶、小肠大肠、命门阳 │
└─────────────────────────┘              └─────────────────────────┘
```
- **深度病理点触诊规则**：
  - **浮取摸气**：表浅肌腠之风寒湿邪；
  - **中取摸血**：肌肉经络之气血运化；
  - **沉取摸脏腑器质**：沉按若触及局部砂砾感、米粒状硬结，指示对应脏器有结石、息肉、囊肿或阴实肿块。
