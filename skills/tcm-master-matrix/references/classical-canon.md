# 古典元典与深度注疏文献库 (Classical Canon Reference Library)

本模块收录中医核心古典元典与历代考据大家之作，作为智能体学术考证与终极真理溯源的基准。

---

## 1. 元典基石
- **《黄帝内经》（素问 · 灵枢）**：中医理论最高源头。重点引用《素问·至真要大论》病机十九条、《阴阳应象大论》阴阳消长、《灵枢·经脉》经络循行。
- **《黄帝外经》（三十七篇）**：传陈士铎本，深入阐发命门为水火之枢、三焦受气之本、三阴三阳媾精化气，补内经之微言。
- **长沙古本《伤寒杂病论》（十二稿本/十六卷本）**：收录刘宪璜家藏古本，较宋本多出《平脉法》《六气主客》《伤寒例》与杂病全帙，为经方气化与古脉法研读不可或缺之秘本。

## 2. 历代注疏考据大家
- **徐灵胎《医书全集》（徐大椿）**：
  - 《医学源流论》：厘清医学正统，辨明时医杂乱、误用补药之流弊；
  - 《伤寒论类方》：最早以方类证之鼻祖，将经方按桂枝、麻黄、葛根、柴胡、承气、四逆等类方归纳，纲举目张。
- **丹波元简 / 丹波元胤《伤寒论集义》**：
  - 日本汉方江户时期考据巨著。遍采汉唐宋元明清历代名医数十家注解，对字句、异文、训诂严密考辨，去粗取精。
- **陆懋修《世补斋医书》**：
  - 清末经方大家。尊张仲景为圣，宗柯琴《伤寒来苏集》与喻嘉言《尚论篇》，力排叶吴温病学派轻浮之说，严正辨析六经传变不可混入三焦卫气营血。
- **陈士铎《石室秘录》（岐伯传本）**：
  - 以治法为核心统摄全书，创制一百二十八法（如“反治法”、“先治法”、“后治法”、“上下同治法”），方药奇谲多变，善用重剂。
- **大塚敬节《临床应用伤寒论解说》**：
  - 日本现代汉方第一人，中医师承学堂核心译著。纯粹立足临床实战，对伤寒方证逐条结合数十万临床病例进行实证检验，绝无浮词。

## 3. 长沙古本与宋本《伤寒杂病论》深度异文考据库 (Changsha Ancient vs Song Edition Variants)

本考据库立足张仲景第十二次亲改定稿——**长沙古本（白云阁藏本 / 刘宪璜旧藏本）**，与通行之**宋本（明万历赵开美复刻宋本）**进行宏观编纂、六气运气与方药字句异文考辨，提供不可随意更改的原始文献事实。

### ① 宏观结构与篇卷编纂对照
- **全书体系**：宋本伤寒与金匮分为两书；长沙古本十六卷合编无间，共 1125 条，合方 397 首，证明仲景医学为“外感内伤一体化”。
- **运气天时**：宋本删去运气篇章；长沙古本独有《六气主客第三》，系统阐明五运六气、标本中气与胜复传变，补齐了经方与天时运气气化推演的失落纽带。
- **脉法地位**：宋本脉法分散；长沙古本卷一、卷二专设《平脉法》《辨脉法》，置于六经分篇之前，确立“以脉定证”的基准地位。

### ② 长沙古本独有《六气主客篇》要义
- 经文：“夫天运六气，风、热、暑、湿、燥、寒，主客相胜，岁有常制，病有变迁……风为百病之长，其胜则散，热胜则燔，湿胜则润，燥胜则坚，寒胜则凝。”
- 学术意义：明确将伤寒六经之病机根源于天运六气之乘除胜复，是经方运气推演的核心母本依据。

### ③ 核心经方条文异文精微逐条对照
- **桂枝汤条（古本卷四第14条 vs 宋本第12条）**：
  - 古本方后注明确载：“温服一升，覆取**微似汗，不可令如水流离**，病必不除。”
  - 临床辨析：微汗方能和营卫，大汗淋漓必伤心阳亡津液。
- **麻黄汤条（古本卷四第43条 vs 宋本第35条）**：
  - 古本明确将**“脉浮紧”**列于正文条目：“无汗而喘，脉浮紧者，麻黄汤主之。”
  - 临床辨析：补足宋本正文略去脉象之疏漏，强调表实闭郁之脉象必须是管壁张力高如琴弦。
- **小柴胡汤条（古本卷八第15条 vs 宋本第96条）**：
  - 古本用**“胸胁痞满”**与**“胁下痞硬”**，较宋本“苦满”更具客观触诊指征。
- **柴胡桂枝干姜汤条（古本卷八第67条 vs 宋本第147条）**：
  - 古本明确载入**“小便不利”**与**“微结”**四字（“胸胁痞满，微结……小便不利者，柴胡桂枝干姜汤主之”）。
  - 临床辨析：解释方中重用牡蛎软坚散结（解微结）、干姜温中化水利小便之机理。
- **四逆汤与通脉四逆汤条（古本卷十一第34条 vs 宋本第323条）**：
  - 古本明确标注生附子生用之力能“破阴绝寒”，干姜用至四两以温中固下，对其人“面色赤”阴盛格阳描述更详。
