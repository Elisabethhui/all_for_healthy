## 📖 项目简介 (Project Overview)

 是一个面向中医自学研习、经方临床思维培养以及 AI 智能体（Agent）赋能的中医多维认知智库与 Skill 体系。

针对传统中医自学与智能体研发中**“学派杂糅导致逻辑冲突”、“文学比喻导致脉诊玄虚”、“现代教材泛化导致本草失真”**三大核心痛点，本项目通过**分层解耦、独立认知透镜与可扩展事实数据库**，将历代中医经典与现代公认实战大师的核心体系实现了工程化还原：

1. **经典元典基准层**：直取《黄帝内经》《黄帝外经》、长沙古本《伤寒杂病论》、徐灵胎医书全集、丹波元简《伤寒论集义》、陆懋修《世补斋医书》、陈士铎《石室秘录》与大塚敬节《临床应用伤寒论解说》等八部元典与深度注疏；
2. **现代四大实战流派（纯粹唯一代表）**：
   - 📐 **胡希恕**：六经八纲 · 方证尖端（几何坐标标尺，有是证用是方）；
   - ☀️ **倪海厦**：温阳动力 · 汉唐人纪（水龙头理论、六大健康金标准、经络针灸）；
   - ⚡ **李可**：扶阳重剂 · 破格救逆（真寒假热/假阳证火眼金睛，大剂附子法度）；
   - 🌿 **郭生白**：生命本能 · 顺势排异（排异反应与自主调节，反对对抗性压制）；
3. **真实名医实战医案数据库 ()**：收录李可、倪海厦、胡希恕经过临床疗效验证的真实病案，以结构化 7 字段元数据（主诉、客观四诊、物理脉象、六经定性、处方煎服、瞑眩转归）作为不可篡改的事实真值；
4. **长沙古本与宋本深度异文考据库 ()**：以张仲景第十二次亲改定稿——**长沙古本（十六卷合编本）**为基准，系统考据其独有之《六气主客篇》《平脉法》及核心经方条文异文；
5. **古医书本草真义**：以《神农本草经》、清·邹澍《本经疏证》（打通经方用药之冠）、清·徐灵胎《百种录》、清·黄元御《玉楸药解》与近代·张锡纯《衷中参西录》为核心，剖析药物天然物理性情与仲景方药配伍真旨；
6. **去玄学物理量化脉诊**：将脉象拆解为【位（深浅）、数（频率）、形（管径张力）、势（回弹力度）】四维物理指标，首创日常实物触觉标定法（木塞、棉被纽扣、吉他琴弦、盘中弹珠、细砂纸、空心葱管）与生物物理脉图；
7. **游朱义古典外治与生态自愈**：融入台湾游朱义老师“人体原厂设计”哲学，补全【开膻中法、荐骨松解、拍打委中】手法经络，以及消渴原生代谢食疗方与全身微颤共振导引操。
