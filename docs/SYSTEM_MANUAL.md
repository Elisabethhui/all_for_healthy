## 一、 快速上手指南 (Quick Start)

### 场景 1：输入复杂病例进行四家会诊推演
当遇到寒热错杂、疑难杂病或病机矛盾时，按以下格式提问：

```text
【病例咨询】
患者女，52岁。
主诉：常年失眠多梦，胸口烦闷，头面部阵发烘热，但下肢极度冰凉畏寒，常年便秘与腹泻交替，舌质淡暗胖大有齿痕，苔白腻滑。
切诊体验：轻摸浮部无力，沉按紧实抗指，关部如绷紧吉他弦（弦脉）。
请启动 tcm-master-matrix 进行全流程交叉推演。
```

**系统将按标准五步返回**：
1. **物理脉象判定**：深浅为沉、管壁为弦、力量为实，定性为“中焦寒水深伏、少阳枢机郁闭、虚阳上浮于外”；
2. **四大名医独立推演**：
   - 胡希恕：少阳太阴并病，推荐柴胡桂枝干姜汤合四逆汤类方；
   - 倪海厦：心火不能下温下焦，水饮上逆化为冷水，需大温下焦阳气、温阳化水；
   - 李可：警告头面烘热为“真寒假热/面戴阳”，严禁妄投知母黄柏等苦寒降火药；
   - 郭生白：指出下焦代谢通路无力，中焦闭锁，应顺应机体调节恢复生化之机；
3. **古本草配伍密旨**：依据邹澍《本经疏证》与徐灵胎《百种录》解析干姜、附子、柴胡、黄芩、甘草在方中的升降浮沉角色；
4. **游朱义外治方案**：立即执行每日早晚“开膻中法”推揉 3~5 分钟，辅以晨起生姜温饮，练习立式微颤共振法；
5. **经典条文印证**：对应《伤寒论》第 147 条柴胡桂枝干姜汤证。

## 二、 脉诊学习指南：在电脑前建立触觉记忆

传统脉学最大的障碍是“只能意会不可言传”。本系统为您提供客观校准指南：

### 1. 手指轻重物理校准 (Three Depths)
- **浮取（皮毛层）**：手指轻轻搭在桡动脉搏动处，仅感知动脉表层的搏动波动，不产生压迫形变（压力大约 30~50g）。
- **中取（肌肉层）**：手指稍微施压，将动脉管壁压下约 1/3，感知脉搏的最强充盈度（压力大约 80~120g）。
- **沉取（骨筋层）**：手指用力下按，几乎将血管压贴到桡骨骨面上，感知深层是否有坚硬搏动（压力大于 150g）。

### 2. 六类核心脉象实物对照操作
| 脉象 | 临床病机 | 实物模拟感知步骤 |
| :--- | :--- | :--- |
| **弦脉** | 肝胆郁结、水饮停聚、少阳病 | 找一根调紧的吉他 2 号或 3 号尼龙弦，手指横向压上去。感受那种边缘分明、硬挺挺、两端有紧绷拉力的线条感。 |
| **滑脉** | 痰湿内停、宿食积聚、妊娠 | 在平底瓷盘里放一颗带少许油珠的玻璃弹珠，手指轻轻按压推滚。指腹下圆滑滚转、滑润无涩阻。 |
| **沉脉** | 里寒、阳虚、痼冷水饮 | 隔着厚厚的大衣，用力摸底下一颗硬质纽扣。轻抚表面无物，深透按压方得硬实。 |
| **浮脉** | 外感表证、虚阳外浮 | 摸浮在水面上的软木塞。轻放指腹立即感知浮力，深按则木塞下陷，指下减弱。 |
| **涩脉** | 气滞血瘀、津液枯竭 | 指腹逆向在 400 目细砂纸上划动。感受那种干涩、顿挫、不顺畅的摩擦滞感。 |
| **芤脉** | 大失血、大伤阴津 | 横按一根煮熟放凉的大葱管。外表管壁饱满，按入其中则空虚软塌，两边有管壁、中间落空。 |

## 三、 游朱义外治与食疗实操规范

### 1. 开膻中推揉四步法
1. **备位**：患者仰卧或靠坐，身心放松，解开衣领露出胸骨；
2. **点穴**：两乳头连线正中，按压有酸麻胀痛感处即是；
3. **旋揉**：用掌根紧贴皮肉，以顺时针方向缓慢深透揉动 81 圈；
4. **推顺**：由膻中穴顺着胸骨向下单向推抚至肚脐上方（水分穴），每推一次配合呼气，重复 18 次，使上胸滞气下沉入腹。

### 2. 消渴（糖尿病）原生饮食调护要诀
- **晨起第一杯水**：严禁冰水或凉开水。必须饮温热淡生姜汤（3片老姜煮水温服），开脾胃水气发动机；
- **进餐顺序革命**：先吃高纤维原生蔬菜 $\rightarrow$ 再吃优质蛋白（鱼肉豆类） $\rightarrow$ 最后吃少量复合根茎粗粮（山药、糙米），杜绝工业精白糖；
- **环境调摄**：脚部常年保暖，禁光脚踩冰冷瓷砖地面。
